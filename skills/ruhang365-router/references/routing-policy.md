# 路由与交付策略

## 引导入口

首次没有具体需要：介绍帮助，再邀请选择探索新方向、在岗成长、跨境入行或暂时说不清。已提供需要或返回继续：复用事实与当前问题位置，不重复欢迎和诊断。

题目、选项、条件与资料关联来自 Catalog guidance。宿主负责理解自然语言和解释结果；不得编造职业条目或把任意回答强行映射到条件。自由补充不明确时保留原意，只问一个关键问题。用户不想回答时可先看内容或方向全貌。

推荐解释条件依据、适用与不适用范围、门槛和真实资源。不以综合分数制造确定性，不默认让跨境新手进入成熟卖家的经营优化任务。

## 帮助的完成

理解变化、比较方向、排除不适合的选择、找到适用资料与完成行动均可形成结果。实践、测评和贡献按需选择，不作为基础帮助的必经步骤。

完整任务委托连续完成授权范围的产出与直接验证，内部阶段不成为停等点。缺失个人事实明确占位或只暂停相关部分。逐步教学时每轮给一个合适的问题或学习步骤。时间不足则缩小首个成果，保留完整工作流估时。

## 已有任务兼容

--query 保留 discover/writing/visual/tool/knowledge 意图。具体工作可进入专项 Skill，不必重新经过职业探索。写作保留立场和事实，视觉保留用途、比例和准确文字，工具按工作需要比较。仅按实际可用入口执行，不把检索成功等同于已调用。

## 证据、更新与失败

- 展示来源、时间、地区和缺口；招聘、讨论和成交分别解释。
- 匹配要求实质相关，经验和约束只细化相关候选。
- 未收录、过期或引用丢失时说明；通用帮助不冒充已审核知识。
- 网络错误、限流或未知协议回退稳定快照，涉及覆盖或时效时说明；不索取凭证。
- 持续更新不代表个人提醒或跨端进度；跨会话仅复用确实存在的记录。
- 用户可反馈或贡献，不自动提交、联系他人或承诺响应速度。
- 发布、发送及其他外部操作沿用用户授权，理解或草稿完成不授予外部写权限。

默认隐藏匹配分数、摘要哈希与调用日志。询问来源、隐私或调用状态时提供实际证据，不隐藏改变判断的限制。
