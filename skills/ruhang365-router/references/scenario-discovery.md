# 场景发现合同

当用户不知道 AI 能做什么时，Router 不依赖远程检索才能给出结果。它先按用户上下文选择一个本地 Profile，再返回 3 个可交付场景和 1 个推荐起点。

| Profile | 识别对象 | 推荐首个成果 |
| --- | --- | --- |
| `local-business` | 门店、小店、咖啡、餐厅、零售、工作室 | 一周获客内容包 |
| `creator` | 自媒体、博主、公众号、小红书、视频号 | 选题到首稿 |
| `office` | 会议、周报、表格、邮件、团队协作 | 会议行动清单 |
| `job-seeker` | 求职、简历、面试、转行、岗位 | 岗位匹配地图 |
| `general` | 无法可靠识别 | 日常任务机会地图 |

本地 Profile 只决定场景起点，不推断用户身份、行业事实或商业结果。Agent 应结合用户原话调整交付物，不得编造数据、客户反馈或成功承诺。

远程资料是补充证据。经过字段白名单后还要通过本地相关性过滤；没有明显匹配时返回 `no_relevant_results`，不得用热门结果填充。
