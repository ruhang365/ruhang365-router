# 场景发现合同

当用户不知道 AI 能做什么时，Router 不依赖远程检索才能给出结果。它读取随 Skill 安装的版本化 Catalog，按身份、目标、经验、约束、交付物和任务词项匹配已审核场景，再返回最多 3 个候选和 1 个推荐起点。

当前公开种子覆盖本地小店内容 / 反馈 / 视觉，以及“一小时吃透自媒体 / IP 行业”入口。收录范围以 Catalog 为准；未收录的办公、求职或其他场景不得继续由代码中的静态 Profile 假装已支持。

匹配结果只决定候选起点，不推断用户身份、行业事实或商业结果。显式约束与 `excluded_constraints` 冲突时必须排除候选；`recommendation_weight` 不得制造无关匹配。Agent 应结合用户原话调整交付物，不得编造数据、客户反馈或成功承诺。

远程资料是补充证据。经过字段白名单后还要通过本地相关性过滤；没有明显匹配时返回 `no_relevant_results`，不得用热门结果填充。
